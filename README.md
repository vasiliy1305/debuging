# debuging

## исправления:

Были исправлены следующие ошибки:

- выход за границы массива в `sum_even`;
- неверное вычисление среднего значения в `average_positive`;
- утечка памяти в `leak_buffer`;
- ошибка `use-after-free`;
- добавлены регрессионные тесты для исправленных функций.

Также выполнена оптимизация функций:

- `slow_fib` — рекурсивная реализация заменена на итеративную (`O(2^n)` → `O(n)`)
- `slow_dedup` — удалены лишние сортировки и вложенный поиск, использованы `sort_unstable()` и `dedup()` 

## Профилирование

Для поиска узких мест использовались **perf** и **FlameGraph**.

Основной горячей функцией являлась `slow_fib`, занимавшая около **> 89** времени выполнения программы. После оптимизации алгоритм был переписан на итеративный, что значительно сократило время выполнения.

## Проверка корректности

После внесения изменений были выполнены следующие проверки:

- `cargo test`
-  `cargo test --release`
- `cargo +nightly miri test`
- `Valgrind Memcheck`
- `AddressSanitizer`
- `LeakSanitizer`
- Бенчмарки до и после оптимизации

Результаты проверки:

| Инструмент | Результат |
|------------|-----------|
| `cargo test` | Все тесты успешно пройдены |
| `cargo test --release` | Все тесты успешно пройдены |
| `cargo +nightly miri test` | Undefined Behavior не обнаружено |
| `Valgrind` | Ошибок памяти и утечек не обнаружено (`ERROR SUMMARY: 0`) |
